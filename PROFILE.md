# legal.ge Public APIs

Georgia's legal marketplace exposing a public, keyless, read-only REST API for matching legal situations to verified specialists, plus an OpenAPI 3.1 contract, an llms.txt agent contract, and an installable MCP server. Multilingual (Georgian, English, Russian) directory of lawyers, law firms, accountants, and legal specialists.

## APIs

- **legal.ge Ask API** — Public, keyless, read-only REST API matching natural-language legal queries to practice areas, services, and a ranked list of verified specialists. Endpoints: POST/GET /api/ask and GET /api/ask/classify. Rate-limited per IP. (`https://legal.ge`)

> REST API (/api/ask, /api/ask/classify) is public and keyless; rate-limited (60/min for ask, 120/min for classify). OpenAPI 3.1 contract at /api/openapi.json is consistently referenced across llms.txt, apis.json, and the MCP README but its raw body could not be fetched directly (tool limitation, not absence). llms.txt confirmed live. The MCP server (@legalge/mcp, MIT, source at github.com/infolegalge/legal.ge-mcp) is a LOCAL/stdio server run via 'npx -y @legalge/mcp' exposing tools find_legal_specialists and classify_legal_intent — it is NOT a hosted HTTP MCP endpoint, so it is not cataloged as an MCPServer property. No AsyncAPI, GraphQL, Postman collection, or published agent skills. Access is free, gated only by per-IP rate limits.
